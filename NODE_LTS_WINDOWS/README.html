Portable Node.js LTS (Windows x64)

Node.js is NOT included in this ZIP. The official installer files must be downloaded on your Windows PC.

  1. Connect to the internet.
  2. Open the NODE_LTS_WINDOWS folder.
  3. Double-click INSTALL_NODE_LTS.bat.
  4. Wait for the official ZIP download and SHA-256 check. The script extracts Node.js into portable/ in the SAME project folder.
  5. Read node-path.txt to find node.exe.

The installer script uses the official nodejs.org v24 LTS release channel and checks the published SHA-256 hash. No admin permissions should be necessary. Windows may ask whether to allow the PowerShell script; review it first.

Node.js is only needed for optional local APIs/build tools, NOT for offline HTML games.
