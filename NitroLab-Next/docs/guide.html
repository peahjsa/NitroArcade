Developer Guide

Open NitroArcade/CrazyArcade/index.html and choose NitroLab Next, or open NitroLab-Next/index.html directly. The three new games work from a pen drive in most modern browsers. Local saving requires browser storage permission.

For API server (optional), install Node.js LTS and run node api/server.js inside NitroLab-Next. GET http://127.0.0.1:8787/api/games. No Node needed for offline games.

NES Emulator Plus is retained from the supplied archive and may require internet. It has not been verified against specific ROM mappers. Only use game files you are authorized to use.

SVG mascot drawings here are new placeholder designs, not exact replicas of existing official mascot artwork. Replace or refine them with your team's approved artwork if needed.
