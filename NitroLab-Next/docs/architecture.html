Three NitroArcade Architectures

1. Experimental Advanced

Compiler pipeline, custom bytecode VM, procedural world engine, GPU compute, ECS runtime, memory allocator, shader transpiler, WASM bindings, deterministic physics, binary serialization, dependency graph, retro-language bridge.

2. NitroArcade Runtime

Frontend: reactive UI, Canvas, WebGL/WebGPU. Runtime: WASM, bytecode VM, ECS scheduler, deterministic simulation. Toolchain: Rust/C++ compilation, shader transpilation, WEB code generation, binary asset pipeline. Optional backend: WebSocket gateway, PHP services, Python workers, webMethods workflows.

3. Programming Languages & Project

HTML, CSS, JavaScript, TypeScript, JSON, Rust, C++, Python, PHP, GLSL, WGSL, WebGL, WebGPU, WebAssembly, WEB, WATFIV, webMethods, binary assets and local API.

Implemented in this addition: HTML/CSS/JS, Canvas2D engine, SVG pixel art, JSON API, optional Node.js API server, sample Python generator. The rest are documented experiments, not falsely claimed to be complete.
