# NES engines
- Existing JSNES emulator is bundled at ../../HexiArcade/nes-emulator/index.html and works with supported mapper types.
- NES Emulator Plus uses EmulatorJS via CDN and needs internet. Its mapper support may differ.
- A second fully offline NES core supporting mapper 40 is NOT bundled. Doing so requires verified third-party core assets and redistribution permissions.
- Do not distribute commercial ROMs without permission.
