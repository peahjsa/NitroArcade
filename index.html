About NitroArcade

NitroArcade is an original browser arcade built as a connected game platform rather than a single game. It grew from the earlier CyberArcade, NitroArcade and UltraArcade projects into the current Small Games, Big Games and Challenge system.

The arcade includes original native games, larger 3D experiences, Hacker Challenge secrets, the hidden Windosill reward through Ruffle, themes, achievements, statistics, recent games, the Prize Toy Shop, Player Hub and shared platform systems.

NitroArcade Online adds account sign-up/login and community comments using Supabase. Public browser code uses only the project's publishable key; database permissions are protected by Row Level Security.

Project team: Prabhav, Zayaan and Shaun. NitroArcade also links to its partner arcade, MacroArcade.

01 // THE PROJECT

What is NitroArcade?

Instead of building just one game, we built an arcade around the idea of variety. NitroArcade combines original browser games, puzzles, physics-based challenges, arcade mechanics and platform features inside one unified interface.


Our vision is to keep expanding it with genuinely different games rather than filling the library with copies of the same idea.

ORIGINAL GAMESDifferent mechanics, from physics and puzzles to arcade challenges.
PRIZE SYSTEMComplete game objectives and build up your arcade prize total.
3D VISUALSAnimated visual elements give the arcade its own atmosphere.
PLAYER FEATURESSearch, favorites, play counts, themes and other arcade tools.
02 // OUR STORY

From one game to two arcades.

CyberArcade began with one hacker-themed game. NitroArcade and UltraArcade followed as experiments. NitroArcade grew into a larger collection of games, challenges and creator tools. Our teammate-led companion project, MacroArcade, adds eight original worlds to the same playable library.

Character Art Lab

Draw your own 16×16 sprites. The player and both custom enemy types use these drawings in play test.

Draw: click/drag pixels. Fill: recolor a connected area. Mirror: flip your art. Every sprite is saved and shared with the game.

NitroScript Behavior Lab

Write safe game-behavior scripts without using raw JavaScript. Enemy A, Enemy B and Turrets can all behave differently.

Commands: MODE CHASE|PATROL|WANDER|FLEE|SENTRY|ORBIT • SPEED number • RANGE number • SHOOT seconds • PROJECTILE_SPEED number • BURST 1-5 • CONTACT damage • TELEPORT seconds • SPREAD degrees. Lines starting with # are comments.
