# NitroArcade Big Games integration

Nitro Clicker, Neon Dodge, Pixel Catcher, Goat Chaos and The Lost Levels now use the same launchGame() player as other Big Games.

They support the regular arcade player UI, recent plays and favorites. The NitroLab pages remain as development/test shortcuts.

Goat Chaos uses its existing implementation; its physics is not a full physics-engine simulation. Online-only engines still require internet.

Open index.html, select Big Games, and launch a game card.
